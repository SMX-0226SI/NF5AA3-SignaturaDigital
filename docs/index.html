Prova de Concepte: PKI Corporativa i signatura electrònica

El client Projecte Nexus us ha demanat modernitzar la seva seguretat. Necessiten garantir la integritat i no repudi dels seus documents interns.

La vostra missió:Desplegar una infraestructura PKI basada en Windows Server 2025 perquè els empleats de Nexus puguin obtenir certificats i signar PDFs oficialment.

Definició del problema: El client vol una infraestructura de PKI que inclogui un portal per la gestió dels certificats. Windows Server disposa d'un rol específic per fer aquesta funció. Normalment, integrat dins un `Active Directory`, però en aquest projecte realitzarem un desplegament sense directori o "Standalone", més flexible però amb més passos manuals.

🎯 Objectius Clau

  • Instal·lar CA a Windows Server 2025.
  • Habilitar inscripció web (IIS).
  • Generar certificats d'usuari.
  • Signar i verificar un PDF.

⚙️ Requisits Tècnics

  • VM Windows Server 2025 (adaptador pont).
  • VM Client Windows 10/11 (adaptador pont).
  • Adobe Acrobat Reader instal·lat al client.
  • Treball en Parelles (Admin/Client).

Dinàmica de Parelles

El projecte requereix coordinació entre dos rols. Utilitzeu els filtres a cada fase per veure només les vostres tasques.

A

Administrador del Servidor

Gestiona Windows Server 2025, instal·la rols (AD CS, IIS) i emet certificats.

B

Usuari Client Windows 11

Accedeix al portal web, instal·la confiança, demana certificats i signa PDFs.

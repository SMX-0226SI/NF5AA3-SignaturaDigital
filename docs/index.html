Prova de Concepte: PKI Corporativa

El client Projecte Nexus us ha demanat modernitzar la seva seguretat. Necessiten garantir la integritat i no repudi dels seus documents interns.

La vostra missió: Desplegar una infraestructura PKI basada en Windows Server 2025 perquè els empleats de Nexus puguin obtenir certificats i signar PDFs oficialment.

Definició del problema: El client vol una infraestructura de PKI que inclogui un portal per la gestió dels certificats. Windows Server disposa d'un rol específic per fer aquesta funció. Normalment, integrat dins un `Active Directory`, tot i que es recomana que mai es desplegui al controlador de domini. En aquest projecte realitzarem un desplegament sense directori o "Standalone" (més flexible però amb més passos manuals).

🎯 Objectius Clau

  • Instal·lar CA a Windows Server 2025.
  • Habilitar inscripció web (IIS).
  • Generar certificats d'usuari.
  • Signar i verificar un PDF.

⚙️ Requisits Tècnics

  • VM Windows Server 2025 (xarxa NAT).
  • VM Client Windows 10/11 (xarxa NAT).
  • Adobe Acrobat Reader instal·lat al client.
  • Treball en Parelles (Admin/Client).

Distribució de la Nota

Pes dels criteris d'avaluació sobre el total.

Guia d'Execució

Seguiu els passos fase per fase. Marqueu les tasques completades per fer un seguiment.

ℹ️

Rol: Administrador de Nexus. Aquesta fase es realitza completament al Windows Server 2025.

1. Preparació i Rols

Configureu el servidor NEXUS-PKI amb IP estàtica.

  • Instal·lar rol: Active Directory Certificate Services (AD CS).
  • Serveis de rol obligatoris: Certification Authority i Web Enrollment.

2. Configuració de la CA

Executeu l'assistent post-instal·lació amb aquests paràmetres:

Tipus: Root CA (Enterprise o Standalone)
Clau: Create New Private Key
Hash: SHA256 o superior
Common Name: Nexus-CA-[VostresNoms]
Validesa: 5 anys
👤

Rol: Empleat de Nexus. Aquesta fase es realitza a la màquina Client (W10/W11).

1. Accés i Cadena de Confiança

Accediu a http://IP-Servidor/certsrv.

⚠ CRÍTIC: Primer heu de descarregar el "CA Certificate" i instal·lar-lo a Entitats de certificació arrel de confiança (Trusted Root) del client. Si no ho feu, el PC no confiarà en Nexus.

2. Sol·licitud del Certificat

Torneu a la web, Request a Certificate -> Advanced.

  • Template: User.
  • Envieu la sol·licitud.

Si la CA és Standalone, l'Admin ha d'aprovar manualment a "Pending Requests" al servidor.

3. Instal·lació

Descarregueu el certificat emès i instal·leu-lo.

Verifiqueu a certmgr.msc (carpeta Personal).

🤝

Rol: Col·laboratiu. Ús pràctic de la infraestructura creada.

1. Signatura (Acrobat Reader)

Creeu i convertiu a PDF un "Acord de Confidencialitat de Nexus".

Aneu a Tools > Certificates > Digitally Sign.

Seleccioneu el certificat de Nexus i guardeu com Acord_Nexus_Signat.pdf.

2. Verificació Creuada

Intercanvieu el PDF amb el company.

✅ Objectiu: Check Verd "Signed and all signatures are valid".
